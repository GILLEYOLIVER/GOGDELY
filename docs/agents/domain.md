# Contexto de domínio para as skills

Antes de gerar uma especificação ou tarefas, ler `docs/MASTER_PLAN.md`, `docs/DECISIONS.md`, `docs/MEMORY.md`, `docs/OPEN_ISSUES.md` e os ADRs relevantes em `docs/adr/`. Usar os termos já empregados nesses documentos, especialmente empresa, filial, estabelecimento, Cliente, Gestão, Entregador, Master, pedido, pagamento confirmado e pagamento simulado.

Relacionar cada entrega às decisões GOG-xxx e indicar se ela é proposta, implementada em laboratório, publicada em homologação ou homologada. Não inferir que uma tela demonstrativa representa faturamento, GPS, autorização multiempresa ou pagamento real.

Se uma skill sugerir decisão diferente de um ADR ou do Documento Mestre, registrar o conflito antes de executar. A orientação de fazer perguntas de entrevista só se aplica quando o proprietário solicitar esse modo; decisões já documentadas podem ser sintetizadas diretamente.
