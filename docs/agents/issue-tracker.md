# Rastreador de trabalho dos agentes

As especificações e tarefas do GOGDELY são registradas nas Issues de `GILLEYOLIVER/GOGDELY`. A descrição de cada issue deve citar os requisitos GOG-xxx, o escopo, critérios de aceite, dependências e limites. Quando uma especificação originar várias tarefas, cada tarefa referencia a issue principal e informa seus bloqueios; não duplicar issues existentes.

Use o conector GitHub disponível no Codex ou o CLI `gh` autenticado. Não colocar credenciais, dados reais, chaves ou URLs privadas de banco nas issues. `ready-for-agent` só é aplicado se o rótulo existir no repositório; na ausência dele, registrar o estado no corpo da issue.

Uma issue de planejamento não autoriza, por si só, integração, deploy de produção, gasto ou uso de dados reais. Seguir as condições de `AGENTS.md` e `CONTRIBUTING.md` para implementar e entregar.
