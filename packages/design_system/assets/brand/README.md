# Proposta de logo GOGDELY

Marca vetorial criada para a direção Azul Elétrico + Grafite do Design System v1.1.

- `gogdely-logo-dark.svg`: assinatura completa sobre grafite.
- `gogdely-logo-light.svg`: assinatura completa sobre fundo claro.
- `gogdely-icon.svg`: símbolo quadrado para ícone de aplicativo.
- `*-preview.png`: prévias rasterizadas para inspeção.

Segunda proposta: `gogdely-logo-v2.svg` e `gogdely-icon-v2.svg`. O símbolo mostra uma rota curta entre dois pontos, com um destino marcado; esta opção permanece separada da primeira para comparação.

O nome preserva a grafia minúscula `gogdely.` mostrada nas referências do proprietário. O símbolo é um G com um ponto de proximidade. As peças foram desenhadas em SVG, sem biblioteca de ícones ou serviço externo. Antes de uso público definitivo, verificar disponibilidade jurídica da marca e aprovar a aplicação visual nas quatro interfaces.
